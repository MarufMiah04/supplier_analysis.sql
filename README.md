# Supplier Performance Analysis — SQL

Five procurement SQL queries built as preparation for my 
purchasing intern placement at Baker Hughes.

## Queries included

1. Total spend by category
2. High risk suppliers flagged for review
3. Average performance by risk level
4. Best value suppliers (high quality, fast delivery, low risk)
5. Contracts flagged for renegotiation

## Tools
SQL (SQLite) | sqliteonline.com

## Context
Built using example supplier data to get familiar with 
procurement analytics before starting at Baker Hughes, June 2026.
